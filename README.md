# PHP Authentication Project

A simple user authentication system built using PHP and MySQL. This project includes user registration, login, logout, and session management.

## Features

- User Registration
- User Login
- Password Hashing
- Session Management
- Logout Functionality
- Basic Form Validation

## Requirements

- PHP 7.0 or higher
- MySQL
- Apache/Nginx (or any web server)
- Composer (optional, if using any libraries)

## Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/php-auth.git
   cd php-auth
   ```

2. Set Up the Database
  Create a MySQL database.
  Import the database.sql file to create the users table.

3. Configure Database Connection
  Open config.php and update your database credentials:
```
$host = 'localhost';
$dbname = 'your_database';
$user = 'your_username';
$pass = 'your_password';
```
4. Run the Project
Place the project in your server's root directory (e.g., htdocs for XAMPP).
Access the project in your browser:
```
http://localhost/php-auth/

```
